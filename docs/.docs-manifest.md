# Manifesto da documentação gerida

Baseline do protocolo `ignore/docs.update.pseudo`: o commit que a documentação
descreve e a impressão digital das fontes declaradas na seção "Fontes" de cada
artefato da tabela do `ignore/docs.pseudo`. Artefato sem seção "Fontes" ou fora
da tabela é autoral — fica fora deste manifesto.

- commit: `23ff7ee` (`23ff7eefa4d10fb9c2a3affa6c52f24712648617`)
- data do ciclo: 2026-09-27
- ciclo: baseline inicial + primeira reconciliação
- fingerprint: SHA-1 git (blob para arquivo, tree para diretório) das fontes em HEAD;
  o agregado é o SHA-1 das linhas `caminho sha` ordenadas; `artefato` é o blob da
  cópia de trabalho (detecta edição manual no próximo ciclo)
